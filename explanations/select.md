# ユーザー名、リポジトリ、パス、ブランチを指定して、そのディレクトリ内(サブフォルダを含む)にある.jsファイルを選択して実行できるブックマークレット

## 使い方
1. google chrome上で、適当なサイトをブックマーク登録する。
2. ブックマークで先程のサイトを選択し、「編集」を押す。
3. 「名前」を任意の名前に変更し、「url」欄に```bookmarklets/urls/select.txt```に書いた.txtファイルをコピー&ペーストする。
4. ペーストしたコードの先頭にあるowner, repo, dir, branchを、指定したいディレクトリのパスに合わせる。branchを省略した場合はmainブランチになる。
5. 「アドレス欄」で登録した名前を検索して、検索候補に出たブックマークを選択する。
6. 実行したい.jsファイル名を選択する。
以上の手順で無事実行されるはず。


## 値の設定値の説明
- owner: ユーザー名です。
- repo: リポジトリ名です。
- dir: 対象のディレクトリです。"" にすると、リポジトリ全体の .js が対象になります。
- branch: ブランチ名です。"" なら既定ブランチを使います。
