# ブックマークレットのURL欄に書くコードの書き方

ブックマークレットのURL欄には、`javascript:` に続けて、**1行でコードを書きます**。

## 基本の形

```
javascript:(function(){ここに処理を書く})();void 0;
```

## 各部分の意味

| 部分 | 役割 |
| --- | --- |
| `javascript:` | 先頭に必ず付けます。ブラウザが、後ろをページ上で実行するコードとして扱います。 |
| `(function(){...})();` | 処理を関数に包んで、その場で実行します。変数がページ側に残らないため、ページのコードと名前がぶつかりません。 |
| `void 0` | 末尾に付けて、全体の結果を `undefined` にします。 |

### `void 0` が必要な理由

`javascript:` のURLは、最後の式の値が `undefined` 以外だと、その値を文字にして、ページを置き換えてしまいます。たとえば結果が `true` だと、ページが「true」とだけ表示されます。これを防ぐために、末尾に `void 0` を付けます。

## `!` を使う書き方

```
javascript:!function(){ここに処理を書く}();void 0;
```

`!function(){...}()` は、`(function(){...})()` の短い書き方です。`!` を付けることで、関数が式として扱われ、そのまま実行できます。

ただし、結果が `true` になりますので、末尾の `void 0` が必要です。圧縮したコードでは、この形がよく使われます。

## `void` だけで済ませる書き方

```
javascript:void function(){ここに処理を書く}();
```

`void` を前に付けると、結果が必ず `undefined` になります。そのため、末尾の `void 0` は不要です。

## 書くときの注意

- **改行を入れません。** 1行で書きます。
- **`//` のコメントは使えません。** 1行にすると、その後ろがすべてコメント扱いになります。コメントが必要なときは、`/* ... */` を使います。
- **`%` は `%25`、`#` は `%23` に書き換えます。** URLとして解釈されるためです。`%` や `#` を含まないコードなら、そのままで構いません。
- **長さに注意します。** 約1万文字を超えると、Android版のChromeでは実行できませんでした。

## 簡単な例

ページのタイトルを表示するだけのものです。

```
javascript:(function(){alert(document.title)})();void 0;
```

## 実行のしかた(Android版のChrome)

1. ブックマークを登録します。URL欄には、上のようなコードを貼ります。
2. アドレスバーに、登録したブックマークの名前を入力します。
3. 候補に出たブックマークを選ぶと、実行されます。

ブックマーク一覧からタップしても、実行されません。必ず、アドレスバーから実行してください。
